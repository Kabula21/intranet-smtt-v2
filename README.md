## Sobre o projeto

A Intranet SMTT V2 é uma solução desenvolvida no formato de plugin para WordPress, destinada à modernização do ambiente digital interno da Superintendência Municipal de Transportes e Trânsito (SMTT).

## Objetivos

- Centralizar informações e recursos institucionais.
- Aprimorar a comunicação interna.
- Facilitar o acesso aos serviços internos.
- Promover a evolução tecnológica do ambiente institucional.
- Facilitar a manutenção e o versionamento do sistema.

## Instalação

1. Acesse a seção Releases deste repositório.
2. Baixe o arquivo ZIP do plugin.
3. Acesse o painel administrativo do WordPress.
4. Navegue até Plugins > Adicionar plugin > Enviar plugin.
5. Selecione o arquivo ZIP e realize a instalação.
6. Ative o plugin e realize as configurações necessárias.

## Versionamento

O projeto utiliza o Git e o GitHub para controle de versões e manutenção do código-fonte.

Versão inicial deste repositório: v2.0.0.

## Segurança e acesso

Projeto de finalidade institucional. O acesso, a utilização e a distribuição do código devem respeitar as políticas de segurança da informação e as autorizações da instituição.
